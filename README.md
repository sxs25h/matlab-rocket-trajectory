# matlab-rocket-trajectory
A MATLAB simulation exploring rocket trajectory and flight performance 

## Overview
A beginner aerospace engineering project using MATLAB to
simulate rocket flight and explore trajectory performance.

## Objectives
- Calculate rocket burnout altitude and velocity.
- Estimate maximum altitude (apogee).
- Examine how changes to simulation inputs affect flight performance.

## Tools
- MATLAB
- MATLAB Onramp (foundational training)

## Key Outputs
- Burnout altitude
- Burnout velocity
- Maximum altitude
- Time to apogee

## Limitations
This is an educational simulation. Results depend on the
model assumptions and inputs and should not be treated as
validated predictions of real rocket flight.
